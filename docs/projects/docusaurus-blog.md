## Quickstart

1. Clone the repository
    - git clone git@github.com:Belsamor/my-dso-blog.git
2. navigate to the repository
    - cd my-dso-blog
3. create branch 'setup blog'
    - git checkout -b "setup-blog"
4. start configuring according to project file
5. commit and push finished configuration
    - git add "filename" to add files to commits
    - git commit to commit all added files
    - git push --set-upstream origin setup-blog to push changes to github
6. pull request and merge with main branch
